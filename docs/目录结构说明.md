## 🎯 目录职责

### `server/` - 服务端
- **职责**：提供 HTTP API 服务和静态文件托管
- **包含**：
  - Express 服务器主文件
  - MQTT Token 代理接口
  - RTC Token 生成接口
  - 环境变量配置
- **启动**：`node server/server.js` 或 `npm run dev`

### `web/` - Web 客户端
- **职责**：前端页面和业务逻辑
- **包含**：
  - 主叫端（caller）：发起呼叫、显示状态
  - 被叫端（callee）：接收呼叫、振铃、接听
  - 公共库（common）：MQTT、RTC、工具函数
- **访问**：通过 server 托管，如 `http://127.0.0.1:3000/caller`

### `sdk/` - 第三方 SDK
- **职责**：存放不通过 npm 安装的第三方库
- **包含**：
  - Agora Web SDK（声网 RTC）
  - 其他浏览器端 SDK
- **引用**：通过 `/sdk/` 路径访问

### `docs/` - 文档
- **职责**：项目相关的所有文档
- **包含**：
  - 使用说明
  - API 文档
  - 通信协议
  - 部署指南
- **注意**：GitHub 会显示根目录的 README.md

## 🔧 关键路径

### 服务端路径引用

```javascript
// server/server.js
// 静态文件目录
app.use(express.static(path.join(__dirname, "..", "web", "public")));

// SDK 目录
app.use("/agora", express.static(path.join(__dirname, "..", "sdk", "Agora_Web_SDK")));

// 加载环境变量
require("dotenv").config({ path: path.join(__dirname, ".env") });
```

### 客户端路径引用

```javascript
// web/public/caller.js
import { ... } from "./common.js";  // 同级目录

// API 请求
fetch("/api/rtc/token");           // 相对路径，由 server 托管
```

## 📝 配置说明

### 环境配置文件位置

- **模板**：根目录 `.env.example`
- **实际配置**：`server/.env`（不提交到 Git）

### 为什么 `.env` 在 server/ 目录？

1. **安全隔离**：服务端配置文件不应与前端代码混放
2. **职责清晰**：只有服务端需要读取环境变量
3. **避免泄露**：前端代码可能被公开，敏感配置独立存放
